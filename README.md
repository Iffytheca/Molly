# Molly

A first-person spooky 3D browser game made by Alizay. Escape a haunted doll through 4 levels, with puzzles and secrets.

**Play:** download this repo and double-click `index.html` in Chrome. No internet needed.

Controls: W A S D walk, mouse look, E use, H hint (3 in the whole game), M mute, Esc pause.

See [GAME-README.md](GAME-README.md) for puzzle answers, secrets and how to add levels.
